# 🤖 Қорқыт Ағай Боты — Орнату Нұсқаулығы

## 📁 Файлдар
- `bot.py` — негізгі бот коды
- `requirements.txt` — керекті кітапханалар
- `Procfile` — Railway үшін іске қосу файлы

---

## 🚀 Railway-ге орнату (тегін, 10 минут)

### 1-қадам: GitHub аккаунт ашу
- https://github.com сайтына кіріп тіркел (тегін)

### 2-қадам: Жаңа репозиторий жасау
- GitHub-та "New repository" басасың
- Атын жаз: `korkyt-bot`
- "Create repository" басасың
- 3 файлды жүктейсің: `bot.py`, `requirements.txt`, `Procfile`

### 3-қадам: Railway-ге кіру
- https://railway.app сайтына кір
- "Login with GitHub" арқылы кір

### 4-қадам: Жаңа жоба жасау
- "New Project" басасың
- "Deploy from GitHub repo" таңдайсың
- `korkyt-bot` репозиторийді таңдайсың

### 5-қадам: Бітті! ✅
- Railway автоматты іске қосады
- Бот жұмыс істей бастайды!
